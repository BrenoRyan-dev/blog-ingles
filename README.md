🌐 Projeto Web — HTML e CSS

Projeto desenvolvido para praticar e demonstrar conhecimentos em desenvolvimento Front-End utilizando HTML5 e CSS3.

🚀 Tecnologias utilizadas
HTML5
CSS3
📌 Sobre o projeto

Este site foi desenvolvido do zero utilizando apenas HTML e CSS  com foco em estrutura, estilização, responsividade e treinar o ingles.

O site possui todo o conteúdo e interface em inglês.

✨ Características
📱 Totalmente responsivo
💻 Adaptado para diferentes tamanhos de tela
🎨 Estilização desenvolvida com CSS
🧱 Estrutura semântica utilizando HTML5
🌎 Interface totalmente em inglês usado para treinar
📐 Layout adaptável para desktop, tablet e celular
🎯 Objetivo

O objetivo deste projeto foi colocar em prática meus conhecimentos de HTML e CSS, desenvolvendo um site completo, organizado e totalmente responsivo.

📱 Responsividade

O projeto foi desenvolvido para se adaptar a diferentes dispositivos:

Desktop
Tablet
Smartphone
